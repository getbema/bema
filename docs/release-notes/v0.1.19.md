Bema 0.1.19 presents decks you opened from an email.

### Fixed
- A deck PowerPoint opened from an Outlook attachment no longer fails with *it doesn't look like a PowerPoint (.pptx) file*. macOS keeps Outlook's folder from other apps, so Bema now reads the notes through PowerPoint instead. The attachment is a read-only copy: save it elsewhere first if you want Bema to write notes into it.
- The guide explains the PowerPoint button's *Add-in Error* about a security certificate, which a work firewall can cause.

### Updating
Bema offers this update automatically within a day, or choose **Bema → Check for Updates…**.
